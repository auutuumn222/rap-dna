# RAP DNA

中文说唱关系宇宙交互 Demo。原生 HTML/CSS/JavaScript，无运行时依赖。

## 运行

需要 Node.js 20+。在本目录运行 `npm start`，打开 http://127.0.0.1:4173 。运行 `npm test` 检查数据完整性、最短路径和 DNA 统计。

## 已实现

- 合作网络：点击人物与连线、拖动地图、缩放、显示或隐藏制作人。
- 路径探索：真实 BFS 计算演示曲库中的多条最短共同演唱路径，支持交换、同人和未收录场景。
- 制作人档案：单曲级角色与作品列表；制作、编曲、混音分别展示。
- 音乐 DNA：选择 3–10 首作品，统计幕后共同署名，导出 SVG 报告卡片、复制分享文字。
- 每日挑战：按北京时间日期生成题目，接受所有有效中间人，支持提示、成绩、作品链与分享。
- 响应式布局、键盘可操作节点、详情弹窗、本机选择与挑战进度保存。

## 数据边界

这是产品交互验证，**不是已核实音乐数据库**。所有关系均标记为演示、未核验。`Do It Like This` 和 `无言以对` 来自用户构想中的案例，未独立核验；其余曲名、所有制作人署名与年份均为演示字段，不代表真实合作。节点是原创唱片式文字图形，不是音乐人肖像。

最短路径只相对于当前数据，且仅采用共同演唱。制作人连线可以独立显示，不进入 Rapper 合作路径。DNA 按单曲去重计数，不推定专辑署名。

正式产品需引入授权或允许使用的作品数据、人物别名归一、原始署名来源、核验状态和日期、持续的数据纠错流程。当前不连接音乐平台或提供音乐播放，无后端或账户系统。

## 文件

`dist/index.html` 页面框架；`dist/style.css` 样式；`dist/app.js` 交互；`dist/data.js` 数据及算法；`server.mjs` 本地静态服务器。
