# 幕后发现：创作者主页与共同幕后

默认入口现在是幕后发现首页。原有歌手档案保留在 `?artist=<key>`，旧的 `#track/`、`#album/`、`#archive` 等链接继续打开 Asen 档案。

- `?creator=<personId>`：跨歌手的创作者主页；支持合作 Rapper、具体角色、年份、歌名 / 专辑筛选、分享链接、查看原始署名与官方播放器。
- `?view=creators`：首页的可搜索创作者目录。
- `?view=common&a=asen&b=masiwei`：两位 Rapper 的共同幕后；支持角色筛选、搜索、交换与分享地址。

## 证据与计数

`scripts/build-creators.mjs` 从 `dist/artists.js` 注册的档案生成 `dist/creator-index.json`。只取实际艺人栏包含当前档案主人的歌曲，以及单曲级的制作人、编曲、混音、母带署名。每条关系必须保留角色、原始字段、来源与核查日期。不从艺人身份或专辑制作角色推断单曲参与。

同一平台歌曲 ID 跨档案去重；不同平台 ID 的单曲、专辑、现场、伴奏等版本仍分开。因此数量称为平台记录数，不宣称独立歌曲数量或创作者完整作品数量。

人物按现有 person ID 连接，绝不凭同名或未经核实的别名合并。仅原始姓名的 `c...` 记录标记为“姓名署名 · 身份待核”，不自动拼入 `n...` 平台艺人主页。头像沿用已有经过 ID 核对的共享注册表；图片缺失或加载失败时回退姓名缩写。

共同幕后有两类结果：

1. **不同作品的交集**：必须能够找到两首不同 ID 的歌曲，优先展示各自未署名另一位 Rapper 的作品。
2. **仅同曲交集**：目前只有同一首歌曲上的共同幕后记录，单独放入折叠区，避免把同曲合作包装为跨作品发现。

角色筛选要求两边都具备该角色；全部角色允许创作者在两首作品中承担不同工作，卡片显示各自的实际角色。

首页三个发现故事由已取得证据的数据生成。优先故事为 ATM Hanson 编曲的 Asen《英雄》（n2754174746）与马思唯《Pop Music》（n2683306407）；两个原始字段都保存在对应歌曲记录中。首页精选仅使用已关联平台艺人账号的创作者，其他故事也必须具有两首不同记录的明确角色证据。共同幕后优先展示这类账号，姓名署名则始终保留身份待核标记。候选数据不足时不补造故事。

## 构建与验证

```sh
node scripts/build-creators.mjs
node --test tests/creators.test.mjs
node tests/creators-browser.mjs
```

发布工作流在上传 GitHub Pages 前重建索引并运行数据语义测试，因此新增已注册歌手会进入下一次发布的索引。浏览器测试覆盖首页发现、跨歌手筛选、原字段、播放器生命周期、直接链接、返回、双人对比、同人空态、未知创作者、原有关系网跳转和 390 / 320 像素布局。

官方播放器的版权、会员、地域及网络限制仍由网易云决定；生命周期测试使用隔离播放器夹具，不把测试结果宣称为所有歌曲均可播放。
