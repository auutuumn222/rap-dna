# 页面职责与探索路线

全站主导航固定三个入口：发现、找共同幕后、Rapper 档案。创作者详情属于发现过程中的人物详情，不再设置平级主导航。隐藏旧歌手下拉框与重复的全局 CTA；歌手页的年表、歌曲、网络、数据说明移入独立的页内导航，滚动时不会改变主导航所属栏目。

首页先解释用途，提供“从喜欢的 Rapper 开始”和“看看两位 Rapper 的共同幕后”两个行动入口，再展示真实案例。创作者目录放入可展开搜索区，默认收起；既有 `?view=creators` 与 `#creators` 链接仍可直接展开搜索。

`?view=rappers` 是统一的歌手选择入口，可搜索姓名与已有艺名。旧 `#rapper-archives` 链接迁移到这里。歌手档案顶部说明页面用途，并提供直接进入幕后模式的按钮。

创作者页标记为“幕后参与”，说明收录范围。从歌手进入时携带已验证的 `fromArtist` 和白名单页内位置，返回合作网络时恢复幕后模式。从共同幕后进入时保留两位歌手，提供明确的返回入口。直接访问的用户可返回幕后发现。同一个人也拥有 Rapper 档案时，展示“幕后参与 / Rapper 作品档案”切换，区分两种视角。

验证：`node --test tests/navigation.test.mjs` 与 `node tests/navigation-browser.mjs`。浏览器验证覆盖三个导航入口、首页引导、歌手搜索、来源返回、档案类型、旧链接以及桌面和 320 / 390 / 768 宽度。旧歌手浏览器测试通过统一的 `switchArtist` 辅助函数使用新的歌手选择路径。
